## 🚀 วิธีการติดตั้งและเริ่มใช้งานระบบ (Installation & Setup)

มีวิธีการและขั้นตอนในการใช้งานดังนี้

1. **ดาวน์โหลดโปรเจกต์ (Clone Repository):**  
   เปิด Terminal หรือ Command Prompt แล้วพิมพ์คำสั่งเพื่อดึงโค้ดลงมาที่เครื่อง:
   ```bash
   git clone https://github.com/athichasa/cat_spa.git
   cd cat_spa
   ```

2. **ติดตั้งไลบรารีที่จำเป็น (Install Dependencies):**  
   ติดตั้งแพ็กเกจของภาษา Python ที่ระบบต้องใช้งาน:
   ```bash
   pip install -r requirements.txt
   ```

3. **สั่งรันระบบ (Start Server):**  
   เปิดการทำงานของเว็บเซิร์ฟเวอร์ด้วยคำสั่ง:
   ```bash
   python app.py
   ```

4. **เข้าใช้งานผ่านเว็บเบราว์เซอร์ (Open in Browser):**  
   เปิดเว็บเบราว์เซอร์ (เช่น Google Chrome หรือ Edge) แล้วไปที่ลิงก์:
   👉 **http://127.0.0.1:5000**
